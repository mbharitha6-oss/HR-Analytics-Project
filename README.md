# HR Analytics Dashboard | Employee Attrition Analysis

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data to understand employee attrition, workforce distribution, and employee-related trends.

An interactive HR Analytics Dashboard was developed using Microsoft Excel to visualize important HR metrics and support data-driven decision-making.

## 🎯 Project Objectives

* Analyze employee attrition and retention patterns.
* Understand workforce distribution across departments.
* Examine attrition based on gender, education, and job roles.
* Identify employee groups with higher attrition counts.
* Present HR metrics through visualizations and a dashboard.
* Support better HR planning and employee retention strategies.

## 📂 Dataset Used

The project uses an HR employee dataset containing information such as:

* Employee details
* Age and gender
* Department and job role
* Education and marital status
* Employee attrition status
* Other workforce-related information available in the dataset
