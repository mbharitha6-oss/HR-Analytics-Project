# HR Analytics Project 📊

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data to understand employee attrition and workforce patterns using Microsoft Excel.

## 🎯 Project Objectives

* Analyze employee data.
* Understand employee attrition patterns.
* Compare attrition across different employee categories.
* Create a dashboard to visualize HR metrics.
* Present insights to support data-driven decisions.

## 🛠️ Tools Used

* Microsoft Excel
* Data Analysis
* Data Visualization
* Charts and Pivot Tables (where used in the workbook)

## 📂 Dataset

The project uses an HR employee dataset to explore workforce information and employee attrition.

## 📊 Dashboard

A screenshot of the HR Analytics Dashboard is included in this repository to provide a visual overview of the analysis.

## 🔍 Analysis Areas

* Employee Attrition
* Department-wise Analysis
* Gender-wise Analysis
* Education Analysis
* Job Role Analysis
* Employee Demographics

## 💡 Key Learning

This project helped me practice data analysis, understand employee attrition patterns, and present HR information through dashboard visualizations.
